## Page strategy

### Homepage

- Primary: content creation app
- Secondary: content creator tools, social media content creation
- Job: explain the full product and convert visitors to the mobile and desktop
  waitlist

### Feature pages

Each page owns one search job. The title, H1, introduction, workflow, and
metadata should use that phrase naturally and then explain Yapper's specific
approach. Do not repeat all category keywords on every page.

### Free tools

Free speaking and creator tools keep their current exact-intent pages. They
should link to the closest product feature and the waitlist, but they should not
be rewritten as product pages.

## Copy rules

- Lead with the user's job, then name the feature.
- Prefer specific nouns such as teleprompter, transcript editor, captions, and
  social media scheduler.
- Use “AI” only when it changes what the feature does or matches a meaningful
  search query. Do not use it as decorative positioning.
- Keep titles readable. Search phrases can appear in descriptions and feature
  sections when a natural title would be clearer.
- Give each page one primary query and two to four supporting queries.

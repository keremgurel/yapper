# Facebook — one complete recording

Aim for about 2–3 minutes plus necessary processing. Start with the shared short introduction.

Before filming: Facebook credentials and a successful test connection still need configuration. Use an authorized test user who can publish to the chosen Page, and have one existing Page Reel. The original 1080 × 1920, 30 fps, 15–20 second sample works within Yapper's current constraints. The new Reel will be public on the Page.

## 1. Connect Facebook

**Do:** Connections → Facebook → Connect. Show Facebook's authorization, the intended user and Page access, then continue back to Yapper.

> “I connect my Facebook account and authorize access to the Page I manage.”

## 2. Choose the Page

**Do:** Open Publish to Facebook Page. Show Choose a Page and the authorized Page names. Select the intended Page and wait for it to save.

> “Yapper lists my authorized Pages. I choose which Page I want to publish to.”

## 3. Show existing Page content

**Do:** Poster → Facebook source tab. Show a real existing Reel from that Page, including its title or description.

> “I can also see this Page's existing Reels inside Yapper.”

Do not describe the current Facebook view counts as insights: the implementation returns placeholder zero counts. This demonstrates reading Page content.

## 4. Review and publish

**Do:** Made in Yapper → choose the original sample → play preview → select only Facebook → edit caption → Publish to 1 destination. Show the Page name and public-Reels notice. Click Publish 1 video to 1 platform.

> “I review my original video and caption, confirm the Page, and authorize a public Reel on that Page.”

## 5. Show the result and disconnect

**Do:** After confirmation, open the actual Reel on Facebook and show its Page, video, and caption. Return to Connections → Facebook → Disconnect. Briefly show the deletion/contact section at https://ypr.app/privacy.

> “Here is the completed Reel on the selected Page. I can disconnect Facebook in Connections, and our website explains how to request deletion.”

Only narrate completion once the actual Reel is present. This single video covers Page listing, reading Page content, and publishing. Meta business/access verification remains separate; follow the actual permission prompts when attaching the recording.

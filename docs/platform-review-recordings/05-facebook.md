# Recording 05 — Facebook user connection and Page Reels

File: `05-facebook-page-connect-publish.mp4`. About 3–4 minutes plus processing. Covers `pages_show_list`, `pages_read_engagement`, and `pages_manage_posts`.

## Before filming — setup still required

Facebook production credentials are currently missing, so the connection is not ready to film. Configure them and verify the complete flow first. Use an authorized app-role test user who manages the intended Page and can create content there. Have an existing Page Reel for the read-permission segment. The sample 1080 × 1920, 30 fps, 15–20 second clip fits Yapper's current Reel preflight constraints.

Each user connects their Facebook account and chooses a Page they manage. This integration publishes **public Page Reels**; use a Page on which you are comfortable making the sample public.

## 1. Introduce

**Do:** Show Yapper, optionally with a brief excerpt of the creation walkthrough.

**Say:**

> “Hi Meta review team. I'm Kerem, the founder of Yapper. This recording shows how a Yapper user connects their Facebook account, chooses a Page they manage, and publishes an original Reel to that Page.”

## 2. Connect through Facebook

**Do:** Open **Connections → Facebook → Connect**. Show the Facebook authorization screen. Confirm the intended user, select the intended Page where Facebook offers that choice, review permissions, and continue back to Yapper.

**Say:**

> “I connect my Facebook account and review the Page access requested by Yapper. I authorize the Page I want to use for this demonstration.”

## 3. Select the Page in Yapper

**Do:** On the Facebook row, open **Publish to Facebook Page**. Show **Choose a Page** before selecting. Display the authorized Page names and choose the test Page. Wait for it to save and show the selected name. Keep the public-Reels explanation visible.

**Say:**

> “Yapper lists the Pages this user has authorized. This is the Page-list permission in use. I explicitly choose this Page as the destination. Reels sent here will be public on the selected Page.”

## 4. Read the Page's existing Reels

**Do:** Open **Poster → Facebook** in the Video source tabs. Wait for the Page's existing Reel to appear. Show its title or description and identify the same Reel on the Facebook Page in another tab.

**Say:**

> “Yapper can retrieve the selected Page's existing Reels so the user can review its content. This demonstrates reading content from the authorized Page.”

Do not describe Facebook view counts as analytics: the current implementation returns placeholder zero counts for Facebook videos. This segment demonstrates reading Page content. If the list does not load, fix that flow before filming.

## 5. Review the video and Page destination

**Do:** Return to **Made in Yapper**. Select the camera-check clip, play its preview, choose only Facebook, and edit the caption. Click **Publish to 1 destination**. Show the final sheet's Page name and public-Reels notice.

**Say:**

> “I select my original video and review its caption. The destination is the Page I chose in Connections. I confirm that this Reel will be public on that Page.”

## 6. Publish and show Facebook

**Do:** Click **Publish 1 video to 1 platform**. Show processing and confirmation. Open the Page's actual new Reel, show the Page name, play the video, and display the caption.

**Say before sending:**

> “I click Publish to authorize this post. Yapper uses the Page publishing permission to create the Reel on my selected Page.”

**Say after publication:**

> “Here is the completed Reel on the selected Facebook Page. The video and caption match what I reviewed in Yapper.”

## 7. Disconnect and deletion instructions

**Do:** Open **Connections → Facebook → Disconnect**, show **Connect**, then show the deletion/contact section of `https://ypr.app/privacy`.

**Say:**

> “The user can disconnect Facebook here. Yapper also provides privacy and data-deletion instructions on its website.”

## Finish check

Show real user authorization, authorized Page list, explicit selection, reading that Page's content, publishing to the same Page, and the actual Reel. Follow each permission's App Review prompt. Meta business/access verification and remaining review requirements are separate from this recording.

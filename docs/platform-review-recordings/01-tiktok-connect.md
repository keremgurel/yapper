# Recording 01 — TikTok connection and account data

File: `01-tiktok-connect-and-library.mp4`. About 2–3 minutes. Covers `user.info.basic`, `user.info.profile`, `user.info.stats`, and `video.list`.

## Before filming

Confirm the integration uses the configured sandbox. Use an authorized test account with at least one of your own public videos. Its profile link, real statistics, and public library must load in Yapper. Record this before making that account private for recording 02. Alternatively, use a separate authorized private account for recording 02 and explain that account change there.

## 1. Introduction

**Do:** Show `https://ypr.app`, then Yapper. Optionally insert the creation walkthrough from recording 00.

**Say:**

> “Hi TikTok review team. I'm Kerem, the founder of Yapper. Yapper is a content studio for creators to develop ideas, record and edit original videos, and publish to their own connected accounts. This first recording shows TikTok Login Kit and the account information displayed inside Yapper. Separate recordings show Direct Post and the inbox workflow.”

## 2. Connect through TikTok

**Do:** Open **Connections → TikTok → Connect**. Show the selected account and requested permissions on TikTok's real authorization page. Scroll as needed, authorize, and let it return to Yapper.

**Say:**

> “I start in Connections and choose TikTok. TikTok asks me to authorize Yapper for this account. I can review the requested access before continuing. I am granting access to my own account for this demonstration.”

## 3. Profile and statistics

**Do:** Show **Connected**, the handle, and the actual followers, following, likes, and posts on the TikTok row. Click **View profile**, show the matching profile, then return to Yapper.

**Say:**

> “Yapper now shows the connected account. The profile link opens the same creator's TikTok profile. The account statistics shown here come from that authorized account. These features use the basic information, profile information, and statistics permissions.”

If the row says **Reconnect for…**, resolve the grant before filming. Read actual numbers if useful; the script intentionally does not invent them.

## 4. Public-video library

**Do:** Open **Poster**. Under **Video source**, select the **TikTok** tab. Wait for real videos. Point to a known title, thumbnail, and view count. Older videos without a Yapper source file may be unclickable; showing their listing demonstrates the read operation.

**Say:**

> “In Poster, the TikTok source tab displays this connected creator's public videos. I can review their titles, thumbnails, and view counts. This is how Yapper uses the video-list permission.”

## 5. Disconnect

**Do:** Return to **Connections → TikTok → Disconnect**. Show the row returning to **Connect**.

**Say:**

> “The creator can disconnect TikTok from Connections. The account is now disconnected from Yapper. In the next recording, I will connect the private sandbox account and demonstrate Direct Post.”

## Finish check

Keep authorization, matching identity, working profile link, actual statistics, nonempty public-video list, and disconnect in the footage. If a requested scope has no working visible feature, resolve that before submission. An empty list does not demonstrate retrieval of video data.
